# 帧影自动签到

MoviePilot V2 插件，站点固定为 `https://framehdr.com`。界面参考癫影自动签到的分组配置、统计卡片和历史表格布局，协议实现独立编写，不复用癫影的登录接口。

## 功能

- Cookie 优先；缺失或被站点明确判定失效时，使用用户名/邮箱和密码登录。
- 登录验证成功后自动回填配置中的 Cookie，后续优先复用；会话轮换同步更新，不丢失当前账号的签到记录。旧版已缓存的登录态在下次成功查询后也会回填。
- 登录前读取当前密码表单、动态字段及登录锁定状态；每次任务至多提交一次密码登录。
- 密码登录未确认成功后暂停自动登录，修改凭证或保存「立即运行一次」后才允许再尝试。验证码需人工在浏览器处理，不绕过验证。
- 每天定时签到、保存后立即执行、结果通知；先查状态，再获取 CSRF 令牌，提交后复查。
- 积分、连续天数、累计天数、当前月签到日历、最近 30 次执行记录；本地最多保留 100 次执行记录。
- 可使用 MoviePilot 系统代理或自定义代理；默认直连。
- 不自动补签、不兑换商品、不消费积分。

## 配置

| 配置项 | 说明 |
| --- | --- |
| 启用插件 | 控制定时执行，默认关闭 |
| 用户名 / 邮箱、密码 | 可单独使用；也可作为 Cookie 失效时的后备登录方式 |
| Cookie | 自动保存，也可手动填写完整的 `name=value; name2=value2`；接受 `Cookie:` 前缀；执行后重新打开配置可看到回填结果 |
| 定时表达式 | 默认 `30 9 * * *`，采用 MoviePilot 的时区；建议配置 Asia/Shanghai |
| 状态查询重试次数 | 0–3 次，仅用于只读签到状态查询，不自动重发签到 POST 或密码 POST |
| 系统代理 | 开启后忽略自定义代理，使用 MoviePilot 的代理配置 |
| 立即运行一次 | 保存后约 3 秒执行真实签到，自动复位，不要求启用定时开关 |

签到日历按北京时间查询；页面为最近一次运行缓存，打开页面不会访问站点或触发登录。换账号后旧账号缓存和记录不会展示，但仍受本地保留上限约束。

## 安全与失败处理

- 密码、Cookie、自定义代理在配置表单中掩码显示；它们仍存储于 MoviePilot 配置，**掩码不是加密**。
- 更新后的有效 Cookie 同步回填配置；完整 Cookie jar（保留路径、有效期）存于插件数据。保护 MoviePilot 管理权限、数据库及备份，不把配置导出后提交 Git。
- 账号凭证变更会使旧会话缓存失效。站点只允许固定 HTTPS 同源请求，不跟随重定向传递密码。
- 日志、通知、统计页面不输出密码、Cookie、CSRF 或原始请求异常。CSRF 不进入签到历史。
- 登录页当前存在空的极验容器，但未观察到启用极验的脚本；未来如启用验证码，插件会停止自动登录或提示登录未成功，需人工更新 Cookie。
- 签到 POST 超时也可能实际成功，插件只复查，不盲目重发。无法复查显示「待确认」，不误报成功。
- 登录失败、账号锁定、网络异常、令牌缺失、非 JSON 响应均保留可读结果；开启通知时会发送提醒。

## 已核对的接口

- `GET /login.php`：密码表单 `loginForm`，`username`、`password`、`login_mode=password`、`remember_me=on` 及动态字段。
- `GET /api/login_status.php?action=login_status`：登录锁定及剩余次数。
- `POST /login.php`：提交密码表单，同一个 Session 保留 Cookie，随后通过签到状态接口确认登录。
- `GET /api/checkin.php?action=init&year=YYYY&month=M`：签到状态、积分、签到记录及 `csrf_token`。
- `POST /api/checkin.php?action=checkin`：multipart 表单提交 `csrf_token`。

## 验证范围

v1.0.2：自动回填 Cookie 并保留会话轮换前的签到记录；日历使用绿色背景、对勾和「已签到」文字组合标识，补签使用空心对勾，今天使用描边及标签。未到日期和缓存缺失日期单独标注，不用颜色作为唯一信息。

v1.0.1：实测未登录签到接口返回 `302 Location: /api/login.php`，现将它与 `/login.php` 一并识别为登录失效，进入账号密码后备登录；不跟随未知、跨域或降级 HTTP 跳转。

接口结构来自登录后网页脚本和未登录的公开登录页；未采集真实账号密码/Cookie，也未提交真实签到或密码登录。离线测试使用脱敏的模拟响应，不代表已在 MoviePilot 宿主或真实账号上验收。

本地测试（Python 3.9+，需 requests、pytz、apscheduler 3.x）：

```sh
python -m unittest discover -s tests -p 'test_framehdrsign.py' -v
```

实际验收：安装后填写自己的凭证，开启「立即运行一次」并保存；核对站点今天已签、插件积分和通知。验证密码登录需使用仅账号密码的配置，注意站点登录次数限制。
