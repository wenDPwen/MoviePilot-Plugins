# Sunny签到

MoviePilot V2 插件，固定适配 `https://sunnypt.top`，使用网站公开前端当前调用的签到协议。

v1.0.2：名称为「Sunny签到」，站点原版太阳 Logo 改用仓库 `icons/sunny-logo.png`，避免站点直链加载失败，并以新路径避开旧缓存。签到与登录逻辑不变。

## 功能

- 优先使用 Cookie；缺失或确认登录态失效时，使用配置中的用户名和密码登录。
- 登录后重新查询会话确认成功，自动将新 Cookie 回填配置；后续优先复用，保存 Cookie 的路径与有效期。
- 密码登录未确认成功（包括超时）后暂停自动尝试，避免反复触发账号限制。核对凭证后修改配置或开启「立即运行一次」允许重试。
- 定时签到、立即运行、结果通知；当天已签只同步状态，不重复提交签到。
- 显示今日魔力奖励、连续签到天数、累计天数、今日状态和补签卡数量。魔力数是今日奖励，不是账户余额。
- 当月绿色签到日历：浅绿卡片、绿色对勾及「已签到」文字，今天单独描边。历史接口只使用确认的日期字段，不区分历史补签。
- 最近 30 次执行记录，最多保存 100 次；详情页只展示缓存，不触发请求。
- 不自动补签，不消耗补签卡，不购买或兑换任何物品。

## 配置

| 字段 | 说明 |
| --- | --- |
| 用户名、密码 | Cookie 缺失或失效时的后备登录方式，也可只填账号密码首次运行 |
| Cookie | 可选，完整 `name=value; name2=value2`；登录成功后自动保存，重新打开配置可查看 |
| 定时表达式 | 默认 `30 9 * * *`，使用 MoviePilot 系统时区；建议 Asia/Shanghai |
| 状态查询重试次数 | 0–3，仅重试只读状态查询；密码登录和签到提交不会盲目重放 |
| 系统代理、自定义代理 | 系统代理开关优先，否则使用自定义代理；均未配置则直连 |
| 立即运行一次 | 保存约 3 秒后执行，开关自动复位；不要求开启定时开关。会实际签到，也允许一次被暂停的密码登录 |

开启二步验证的账号请在浏览器完成登录后填写 Cookie。站点登录接口的 `code` 是可选二次验证码，插件不保存动态验证码或二步验证密钥，也不会绕过验证。验证码、访问挑战或站点限制需要人工处理。

## 协议及凭证保护

- 网站会话：`GET https://sunnypt.top/api/auth/session`，读取临时 `accessToken`。
- 账号密码登录：`POST https://sunnypt.top/api/auth/session/login`，JSON 字段 `username`、`password`、空 `code` 和 `rememberMe: true`，重新查询会话确认成功。
- 状态：`GET https://api.sunnypt.top/api/v1/attendance/status`。
- 签到：`POST https://api.sunnypt.top/api/v1/attendance/check-in`，每次运行最多提交一次，然后查询状态确认结果。
- 日历：`GET https://api.sunnypt.top/api/v1/attendance/monthly?year=YYYY&month=M`；读取 `records[].date`。
- 网站 Cookie 与 API 使用独立会话。Cookie/密码只发往固定网站；API 只发送临时 Bearer 令牌，不携带网站 Cookie。令牌只保存在内存，不写入配置、记录或日志。
- 固定 HTTPS 主机、路径和方法，不跟随跳转，不输出原始响应、网络异常详情或凭证。
- Cookie/密码保存在 MoviePilot 配置与插件数据中，输入框掩码不等于加密，请保护管理权限及备份。
- 网络/解析异常不等于密码错误，不触发盲目自动登录；明确未登录时才使用账号密码后备。
- 签到提交超时后只查询结果；未确认成功标记「待确认」，不重复提交。日历同步失败不影响已确认的签到状态，界面显示警告。

离线测试覆盖 Cookie 优先、密码后备、Cookie 自动回填与重启复用、失败暂停、手动重试、双会话隔离、跳转阻断、签到状态复查、日历降级及敏感信息保护。仍需安装到实际 MoviePilot 验证服务器端登录、签到与界面。
