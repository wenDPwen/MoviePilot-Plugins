# 福利吧自动签到

MoviePilot V2 插件，固定站点 `https://www.wnflb2023.com`，适配 Discuz! X3.4 的 `fx_checkin` 签到插件。独立安装，不依赖帧影插件。

## 功能

- Cookie 优先，缺失/失效时使用论坛用户名、密码及可选安全问题登录。
- 登录经站点页面确认后自动将有效 Cookie 回填到插件配置；后续优先复用，并保存 Cookie jar 的路径与有效期。
- 密码登录未确认成功后暂停自动登录，修改凭证或手动「立即运行一次」后再允许尝试，避免反复触发论坛锁定。
- 定时签到、立即执行、签到结果通知；先查状态和 formhash，提交一次，随后查询页面核实结果。
- 福利余额、连续天数、累计天数、今日状态；另列论坛总积分和金币，不混淆积分单位。
- 月度绿色签到日历：实心对勾为已签、空心对勾为补签，今天单独描边；最近 30 次执行记录，最多保留 100 次。
- 支持系统代理和自定义代理，不自动补签、不购买、不兑换、不花费金币。

## 配置

| 配置 | 说明 |
| --- | --- |
| 论坛用户名 / 密码 | 账号密码登录，不保证支持邮箱作为账号；可留空而仅配置 Cookie |
| 安全问题 / 答案 | 与论坛账号安全设置一致；未设置问题则选择「未设置」，无需答案 |
| Cookie | 可选，完整 `name=value; name2=value2`；登录成功后自动保存，重新打开配置可看到回填 |
| 定时表达式 | 默认 `30 9 * * *`，使用 MoviePilot 系统时区，建议 Asia/Shanghai |
| 状态查询重试次数 | 0–3，只重试读取状态；签到虽使用 GET，但不会作为只读请求重复执行 |
| 系统代理 | 开启后优先使用 MoviePilot 代理，否则使用自定义代理或直连 |
| 立即运行一次 | 保存后约 3 秒执行真实签到，自动复位；不要求启用定时开关 |

页面展示缓存，打开详情不会发起登录或签到。日历为站点当月记录，查询失败时显示警告，空白/无记录不能证明当天未签到。

## 协议与保护

- 查询状态：`home.php?mod=spacecp&ac=credit&showcredit=1`，解析 `discuz_uid`、退出链接、`fx_chk_menu`、签到按钮与积分字段。
- 日历：`plugin.php?id=fx_checkin:ajax&date=YYYYMM&inajax=1`，解析 XML CDATA 中的 JSON，不执行站点 JavaScript。
- 签到：页面脚本提供的 `plugin.php?id=fx_checkin:checkin&formhash=...`，模拟 Discuz 弹窗请求，固定同源。
- 登录：读取 `member.php?mod=logging&action=login` 的动态表单 action、loginhash、formhash，再提交用户名、密码、安全问题、答案和自动登录选项。
- 原始响应/异常不写日志。配置掩码不等于加密，账号、密码、答案及 Cookie 保存在 MoviePilot 配置/数据中，请保护管理权限与备份。
- 不采集浏览器凭证。发现验证码时停止自动登录，需人工浏览器登录后更新 Cookie；不会尝试绕过验证码或站点保护。
- 未知重定向、非 HTTPS、非本站地址均拒绝，避免向外部发送凭证。
- 请求超时后只查询确认状态，不盲目重放签到。复查失败标记「待确认」，不根据响应中孤立的“签到成功”文本误报成功。

## 验证范围

v1.0.3：用户预填的论坛登录表单已通过浏览器提交并确认成功（未执行签到）。修复插件严格解码导致的复查失败，支持响应头、meta/XML 编码声明、UTF-8/GB18030 回退和少量损坏字节；浏览器验证不等于 MoviePilot 端登录验证，更新后仍需实站复测。

v1.0.2 为登录诊断版，尚未确认实站密码登录失败根因。失败时输出 HTTP 状态、HTML/XML 类型、是否返回登录表单、是否存在认证 Cookie 等布尔信息，不输出 Cookie 值、原始页面或重定向地址；兼容 Unicode 转义和带 HTML 标签的错误文案。移除浏览器 `form.submit()` 不会提交的按钮 `loginsubmit=true`，保留 action 中的 `loginsubmit=yes`。

v1.0.1 对齐站点 `ajaxpost` 的 `inajax=1` 参数及登录页 Referer，并读取登录响应生成固定的脱敏错误分类。提交后的网络/解析失败单独提示，不再统一归为密码登录失败。现有旧版通用日志不足以确定具体根因，仍需更新后验证。

已读取登录后的签到状态、积分结构和日历接口，以及公开登录页。已按用户授权提交浏览器预填登录表单并确认登录成功，未读取或复制密码，未提交签到或补签请求；尚未验证 MoviePilot 服务器端的真实账号登录。

离线测试覆盖登录态识别、Cookie 回填、安全问题、验证码阻断、签到结果复查、XML/JSON 解析、日历和积分单位。尚需安装到实际 MoviePilot 验收登录、签到和界面。

```sh
python -m unittest discover -s tests -p 'test_*.py' -v
```

需要 requests、pytz、apscheduler 3.x。插件包必须包含同一 `wnflbsign` 目录下的 `__init__.py` 和 `site.py`。
